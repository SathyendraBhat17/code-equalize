# Code Equalize

Code Equalize is an AI-powered VS Code extension that provides simplified, context-aware error explanations and debugging assistance in a programmer's preferred language.

## Problem

Programming errors are often difficult for beginners to understand because compiler and runtime messages can be highly technical and are usually presented only in English. This creates a learning barrier for many students and aspiring developers.

## Solution

Code Equalize uses AI to analyze errors, provide context-aware explanations, and present them in a user's preferred language while preserving technical accuracy. The goal is to make debugging more accessible, educational, and beginner-friendly.

## Features

* AI-assisted debugging and error analysis
* Multilingual error explanations
* Context-aware suggestions for faster issue resolution
* Retrieval-Augmented Generation (RAG) for accurate responses
* ChromaDB-based knowledge retrieval
* Beginner-friendly explanations without losing technical accuracy

## Tech Stack

* Node.js
* VS Code Extension API
* ChromaDB
* Gemini API

## Status

🚧 Currently under development.

The project is focused on improving programming accessibility and helping developers understand, learn from, and resolve errors more efficiently.
