# Code Equalize

Code Equalize is an AI-powered VS Code extension that provides simplified, context-aware error explanations and debugging assistance in a programmer's preferred language.

## Features

* AI-assisted debugging and error analysis
* Multilingual error explanations
* Context-aware suggestions for faster issue resolution
* Retrieval-Augmented Generation (RAG) for accurate responses
* ChromaDB-based knowledge retrieval
* Beginner-friendly explanations without losing technical accuracy

## Tech Stack

* Node.js
* VS Code Extension API
* ChromaDB
* Gemini API

## Status

Currently under development. Focused on improving programming accessibility and helping developers understand and resolve errors more efficiently.
